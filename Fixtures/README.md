# Fixtures

Recorded calls, hand-verified golden transcripts, and sample speaker
embeddings used by the accuracy harnesses (plan sections 16.2 and 16.4).

`diarization/two-speaker.caf` is a small synthetic 2-channel CAF (L = near,
R = far) generated by `Scripts/generate-diarization-fixture.sh`. It is not a
personal recording. `diarization/two-speaker.rttm` is the matching reference
timeline for the DER harness.

Large real-call audio should come in via Git LFS when it lands.
